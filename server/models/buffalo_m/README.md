# Buffalo ONNX Face Recognition Models

Place the following 5 InsightFace Buffalo ONNX model files in this directory (`server/models/buffalo_m/`):

1. `det_2.5g.onnx` (~3.2 MB) - SCRFD Face Detection
2. `w600k_r50.onnx` (~174 MB) - ArcFace 512-d Face Embedder
3. `2d106det.onnx` (~5.0 MB) - 2D 106-point Landmark Detector
4. `1k3d68.onnx` (~143 MB) - 3D 68-point Landmark Detector
5. `genderage.onnx` (~1.3 MB) - Gender and Age Estimator

These models can be downloaded from the official InsightFace model releases or repository.
